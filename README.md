# 📊 Exploratory Data Analysis (EDA) – E-Commerce Sales Dataset

## 📌 Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on a large E-Commerce Sales dataset containing approximately **2.24 million order records**.

The main objective is to explore, clean, analyze, and visualize the data to identify meaningful patterns, trends, and business insights related to sales performance, customer behavior, product performance, profitability, and business operations.

The analysis uses Python and its popular data analysis and visualization libraries.

## 🎯 Project Objectives

The key objectives of this project are:

- Analyze overall sales and profit performance.
- Identify the best-performing product categories.
- Understand customer purchasing behavior.
- Analyze sales performance across different regions.
- Identify popular payment methods.
- Understand the impact of discounts on profitability.
- Analyze product returns and refunds.
- Evaluate delivery and shipping performance.
- Explore inventory and stock patterns.
- Analyze marketing channels and customer behavior.
- Identify time-based sales trends.
- Discover relationships between different business variables.

## 📂 Dataset Description

The dataset contains approximately 2.24 million records with information related to:

## 🔍 Project Workflow

The analysis is performed through the following steps:

1. **Dataset Understanding** – Exploring the dataset structure, dimensions, columns, and data types.
2. **Missing Value Analysis** – Identifying and checking missing values.
3. **Duplicate Analysis** – Checking duplicate records.
4. **Categorical Analysis** – Exploring categorical variables and their distributions.
5. **Numerical Analysis** – Understanding numerical variables using descriptive statistics.
6. **Sales Analysis** – Exploring sales performance and revenue patterns.
7. **Category vs Sales** – Comparing sales across product categories.
8. **Regional Analysis** – Analyzing sales performance across regions.
9. **Customer Analysis** – Understanding customer segments and purchasing patterns.
10. **Product Analysis** – Exploring product-level performance.
11. **Payment Analysis** – Analyzing different payment methods.
12. **Discount Analysis** – Understanding discounts and their relationship with sales and profit.
13. **Return Analysis** – Exploring product returns.
14. **Delivery Analysis** – Evaluating delivery and shipping performance.
15. **Inventory Analysis** – Exploring stock and inventory patterns.
16. **Marketing Analysis** – Understanding marketing channels and customer behavior.
17. **Time-Series Analysis** – Exploring sales trends over time.
18. **Data Visualization** – Creating visual representations to communicate important patterns and insights.

## ▶️ How to Run the Project

1. Clone this repository:

```bash
git clone https://github.com/shammaskattil24-byte/project_eda-1.git
```

2. Navigate to the project directory:

```bash
cd project_eda-1
```

3. Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn jupyter pyarrow
```

4. Open Jupyter Notebook:

```bash
jupyter notebook
```

5. Open `eda2.ipynb` and run the cells.

**Note:** Make sure the dataset is available on your system and update the dataset file path in the notebook before running it.
